Questions founders ask

Clear boundaries before you delegate revenue work.

Hosted and self-hosted deployments use the same module contracts and approval model.

How do I actually use Trevra?

You give Claude Code, Codex, or another agent a GTM outcome. The agent calls Trevra modules, while Trevra records the run and stops at the approval boundary for consequential work.

Can an agent send messages or create invoices by itself?

Only inside the policy you set. Consequential actions can require manual approval, and the exact approved payload is hashed before execution.

How are community modules shared safely?

Modules are versioned through GitHub and declare their schemas, side effects, and approval requirements. Validation and tests run before a catalog release.

Can I self-host Trevra and keep my data?

Yes. The application uses PostgreSQL, the runner is open, and the ledger, evidence, configuration, and exports can remain in infrastructure you control.
